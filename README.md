# ライブ配信・ゲーム利用ルール

## 基本方針

本ルールはプレイヤーを責めるためのものではなく、コミュニティ内の公平性と安心感を守るためのものです。

ゲームの楽しみ方は人それぞれですが、

* 他プレイヤーへ著しく不公平な影響を与えないこと
* 視聴者や参加者が不快にならないこと
* 運営やコミュニティに迷惑をかけないこと

を大切にします。

---

# 1. 対人戦・ランキング・大会企画

対人戦、ランキング、大会、競技イベントでは、ゲーム運営・開発元が公式に提供、または使用を明確に許可しているツールのみ使用可能とします。

また、公式ツールであっても、

* 本来の用途を逸脱して優位性を得る行為
* 他プレイヤーとの公平性を損なう行為

は禁止します。

---

# 2. 協力プレイ・身内マルチプレイ

協力プレイや身内マルチプレイでは、

* 日本語化MOD
* UI改善MOD
* バグ修正MOD
* クロスプレイ対応プラグイン
* 難易度調整MOD
* ロールプレイ支援ツール
* 配信支援ツール

など、ゲーム体験の向上を目的とした利用は原則許可します。

ただし、

* チート機能
* 自動操作
* 不正な情報取得
* 他プレイヤーへ著しく不公平な優位性を与えるもの

は禁止とします。

---

# 3. 配信・動画での利用

配信や動画では、

* 視聴者に誤解を与えないこと
* 不正行為を推奨しないこと

を重視します。

チート・自動化ツール・不正行為を配信上で紹介したり推奨したりする行為は禁止します。

一方で、

* 日本語化MOD
* バグ修正MOD
* クロスプレイ環境
* 配信補助ツール
* 難易度調整MOD

など、一般的なゲーム体験向上を目的とするものは利用可能です。

---

# 4. 個人利用

個人プレイやVCのみでの交流については、各ゲームの利用規約に反しない範囲で個人の判断を尊重します。

ただし、

* 違法行為
* 他者への迷惑行為
* コミュニティ内への持ち込み

は禁止します。

---

# 5. マクロ・自動化

以下は禁止です。

* 対人戦でのマクロ
* ランキング競争でのマクロ
* 放置稼ぎを目的とした自動化
* 他プレイヤーより著しく有利になる自動操作

一方で、

* 単純な操作補助
* 身体的事情へのアクセシビリティ目的
* 協力プレイにおける軽微な補助

については、状況に応じて認められる場合があります。

---

# 6. 判断に迷った場合

判断に迷う場合は以下を基準とします。

* 他プレイヤーに不公平か
* 視聴者が不快に感じるか
* 大会で使用されたら問題になるか
* ゲーム体験向上が主目的か

迷った場合は事前に管理側へ相談してください。

---

# 7. 具体例

### 原則OK

* MinecraftのGeyser / Floodgate
* GSit
* 日本語化MOD
* REPOの難易度緩和MOD
* Discord連携
* OBS連携
* TRPG支援ツール

### ケースバイケース

* 軽微な操作補助マクロ
* UI拡張
* 情報整理ツール

### NG

* X-Ray
* WallHack
* AimBot
* KillAura
* AutoFarm
* 放置稼ぎBOT
* 対人戦での連打マクロ
* ランキング競争での自動化
